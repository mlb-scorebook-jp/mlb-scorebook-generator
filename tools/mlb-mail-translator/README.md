# MLB番記者メール自動翻訳

Appleメールのローカルメールボックス「MLB番記者」から新着を読み、日本語訳を次の場所へ保存します。

`書類/MLB番記者_日本語訳/YYYY-MM-DD/`

原文メールの移動・削除・既読化・送信は行いません。

## 初回テスト

1. OpenAI APIの管理画面でAPIキーを作成します（ChatGPTの契約とは別です）。
2. `setup.command` をダブルクリックします。
3. APIキーを入力します。キーはMacのキーチェーンに保存され、設定ファイルやGitには入りません。
4. 直近5件の翻訳結果を `書類/MLB番記者_日本語訳` で確認します。

## 手動実行

`run.command` をダブルクリックします。翻訳済みのメールは再処理しません。

## 自動実行

翻訳結果を確認してから設定します。Mac起動中に一定間隔で実行する方式で、Appleメールの原文には触れません。

## 設定変更

- メールボックス名: 環境変数 `MLB_MAILBOX_NAME`
- 翻訳モデル: 環境変数 `MLB_MAIL_TRANSLATOR_MODEL`
- APIキーの保存名: `mlb-mail-translator-openai`
